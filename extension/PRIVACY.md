## Summary

QuakeSignal for Chrome is a free and open source earthquake monitor. Its single
purpose is to monitor public earthquake data and show browser notifications and
alarm sounds that you have enabled.

It connects only to `wss://ws-api.wolfx.jp` for public earthquake data. It
stores only alert preferences, recent public earthquake events, and connection
status, all in Chrome's local extension storage on your own device. It does not
collect, sell, share or transmit personal or sensitive user data, and it does
not read browsing history, website content, cookies, account information or
precise location.

Questions can be filed through the public
[QuakeSignal issue tracker](https://github.com/TastyHeadphones/QuakeSignal/issues).
